Legacy Gaming.

Next-generation games. Older hardware. Open-source innovation.

We build small graphics experiments for people who still rely on older GPUs. Our first test bench pairs a 4 GB Radeon RX 570 with a Xeon E5-2666 v3.

Resolution under test

Two passes, one output image. We changed the resolution of the terrain pass and measured the GPU time through the final bilinear composite.

Method and raw samples

The lower resolution cost 65.3% less GPU time in this scene. RGB image error was 7.613 on a 0–255 scale. Each run recorded 32 timed intervals per profile after eight warm-up frames.

Can it run GTA VI?

GTA VI remains untested here. The referenced VIctory world path asks for Shader Model 6.6 and mesh shaders. This machine reported Shader Model 6.5 and mesh tier 0. Source and security

Marvisak and the VIctory contributors authored the reference project. Its asset policy excludes a BCPack table from its license. Our lab uses original code, its own Git history and synthetic materials.
