# Outreach copy

Prepared for voluntary, targeted use. These are drafts. Check each community's posting rules before posting and disclose the sponsorship. Use one relevant message per community.

## GitHub · project announcement

World Finance Legacy Gaming is open for contributions. We measured our own procedural scene on a 4 GB Radeon RX 570, published all 256 GPU intervals and included the quality loss from upscaling. Reproduce the baseline or propose a small, rights-cleared test of a legacy rendering path. World Finance sponsors the work. [Code and instructions](https://github.com/luizendIA/worldfinance-legacy-gaming)

## Reddit · low-end gaming

Owners of older GPUs: what does rendering at half resolution actually buy on your card? On our RX 570, the same synthetic terrain cost 4.343 ms at 720p and 1.505 ms at 360p upscaled to 720p. We include the raw runs and image error. We would like a second rig to repeat the protocol. This is an independent World Finance research project; GTA VI is untested. [Method and data](https://github.com/luizendIA/worldfinance-legacy-gaming/tree/main/benchmarks)

## Discord · graphics or hardware channel

We have a small Windows graphics lab that runs a generated terrain scene with no game files. A second Polaris machine would help us understand driver variation. If your server welcomes research projects, join the discussion with your adapter and driver. World Finance sponsors this volunteer effort. [Discussion](https://github.com/luizendIA/worldfinance-legacy-gaming/discussions)

## X

We measured an original terrain scene on a 4 GB RX 570: 4.343 ms at 720p, 1.505 ms at 360p upscaled. Raw timings and image error are public. GTA VI remains untested. Volunteer contributors welcome. Powered by World Finance. https://github.com/luizendIA/worldfinance-legacy-gaming

## Legacy-hardware forums

A 4 GB card still makes a practical graphics test bench. Our first setup uses a Xeon E5-2666 v3, RX 570 and Windows 10. We would welcome a replication on a similarly priced system, including unsuccessful builds and slower results. Please share driver, OS, build and per-run JSON. [Contribution guide](https://github.com/luizendIA/worldfinance-legacy-gaming/blob/main/CONTRIBUTING.md)

## AMD communities

Our RX 570 driver reported Shader Model 6.5 and Mesh Shader Tier 0. We are collecting comparable feature queries from other Polaris boards and drivers alongside an independent D3D11 terrain test. AMD has no role in this project. [Hardware matrix](https://github.com/luizendIA/worldfinance-legacy-gaming/tree/main/benchmarks)

## Rust communities

VIctory's Rust workspace is one reference for our independent legacy-hardware research. Its data policy led us to publish a new source tree and retain a pinned citation. The current probe is C++/HLSL. Rust contributors interested in a small reader for the timing JSON or a Vulkan capability probe can help design a cross-language parity test. [Research issues](https://github.com/luizendIA/worldfinance-legacy-gaming/issues)

## Computer graphics communities

We are looking for review of a synthetic meshlet-to-indexed-draw experiment for hardware reporting Mesh Shader Tier 0. The proposed first acceptance test compares coverage and depth against a CPU reference before measuring GPU time. Our existing two-pass terrain fixture provides a separate resolution baseline. [Technical roadmap](https://github.com/luizendIA/worldfinance-legacy-gaming/blob/main/ROADMAP.md)

## Open-source development forums

World Finance is funding an independent investigation into accessible graphics hardware. A third-party table in a reference repository had no confirmed redistribution grant, so we started an original implementation. We welcome reviewers for artifact provenance, Windows CI and reproducibility across toolchains. [Security and provenance report](https://github.com/luizendIA/worldfinance-legacy-gaming/blob/main/reports/upstream-review.md)
