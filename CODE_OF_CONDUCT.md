# Community conduct

Welcome contributors of every background, language and hardware budget. Discuss measurements and code with care. Credit prior work, make space for beginners and respect requests for privacy.

Harassment, threats, personal attacks, doxxing, discriminatory treatment and unsolicited promotion are grounds for moderation. These expectations cover Issues, Discussions, pull requests and project events.

Report public content through GitHub's reporting controls or privately to a project maintainer through available GitHub channels. Include links and relevant context. Maintainers may hide content, ask for corrections, restrict participation or remove repeat offenders. A contributor may request reconsideration by another available maintainer.
