# Contributing

Fork this repository, create a topic branch and open a pull request against main. Small, reproducible changes are easiest to review. English and Brazilian Portuguese submissions are welcome. Ask design questions in [Discussions](https://github.com/luizendIA/worldfinance-legacy-gaming/discussions) and report defects through [Issues](https://github.com/luizendIA/worldfinance-legacy-gaming/issues).

For a graphics change, include the workload revision, OS build, adapter name, driver, build configuration, resolutions, order, unmodified timing arrays and an image-quality check. Report cold-start or CPU cost separately. Label WARP and physical adapters explicitly. An inconclusive or slower result is worth reporting.

Use generated fixtures and document their origin and license. Keep proprietary SDKs, game files, screenshots from commercial titles, dumps, keys and personal paths out of submissions. Run the README build, CTest and `python tools/verify.py` before opening the PR. Reviewers check provenance, correctness, measurement scope and security. Maintainers request independent review for external contributions; competing implementation proposals belong in separate PRs.

Contributions must be yours to license under GPL-3.0-or-later. List third-party notices before proposing imports. [Code of conduct](CODE_OF_CONDUCT.md) · [Security](SECURITY.md)
