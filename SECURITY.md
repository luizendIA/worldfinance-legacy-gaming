# Security

The maintained line is main. Report sensitive findings through [GitHub private vulnerability reporting](https://github.com/luizendIA/worldfinance-legacy-gaming/security/advisories/new). Include the commit, expected and observed behavior and a minimal description using synthetic inputs. Omit credentials, private machine paths and commercial game material. Use public Issues for ordinary rendering defects.

The lab runs an original embedded shader and takes no external scene input. Build locally as an ordinary user, keep Defender enabled and review changes to workflows and capture paths. Only use --capture with an intended output file. For independent upstream testing, keep third-party executables in a disposable isolated environment with no personal folders or wallet data.

Maintainers triage the affected revision and scope, coordinate a fix and publish an advisory with the fixed commit when appropriate. [Initial audit](reports/upstream-review.md) · [Build integrity](reports/build.md)
